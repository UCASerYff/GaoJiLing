# 搞机灵 V1.09

<img src="Assets/AppIcon.png" width="96" alt="搞机灵：黑底白字的机灵图标">

电脑的小动静，一眼就知道。

搞机灵是一款原生 macOS 边缘系统监控工具，使用 SwiftUI、AppKit、Mach/IOKit/libproc 和 SQLite。监控记录保存在本机，无第三方运行时，无 AI 和账号。

[下载最新版](https://github.com/UCASerYff/GaoJiLing/releases/latest) · [V1.09 发布页](https://github.com/UCASerYff/GaoJiLing/releases/tag/v1.09) · [使用说明](使用说明.txt) · [验证范围](VALIDATION.md)

## 安装

支持 Apple Silicon Mac，最低 macOS 14；当前安装包为 ARM64，不包含 Intel 版本。

从 GitHub Releases 下载 DMG，打开后将“搞机灵.app”拖入“Applications”。更新时先退出旧版，再替换应用；历史、任务和设置保存在独立的数据目录中。发布页同时提供安装包的 SHA-256 校验文件。

当前公开安装包使用本地 ad-hoc 签名，未作 Apple Developer ID 签名或公证，会受到 Gatekeeper 检查。也可以按下方步骤从源码构建。

## 功能

- **悬浮面板**：收起时仅显示竖线，支持点击、悬停呼出。按住竖线可自由拖动或跨屏移动，松手保留当前位置，靠近左右边缘才吸附；位置和所在屏幕自动保存。展开面板跟随竖线，选择空间较充足的一侧并保持在屏幕可见范围内。展开后可按住顶部 CPU 展示区域拖动，收回后的竖线跟随新位置。面板无顶部栏；鼠标进入后移出会快速自动收回，点击面板外或按 Esc 也可收起。首次快捷键呼出保留短暂宽限，底部提供暂停/继续采样和打开主窗口按钮。
- **实时监控**：CPU、内存压力、压缩内存、Swap、网络与磁盘吞吐、应用排行，以及按机型可读取的传感器。
- **历史回看**：查看最近 24 小时趋势，定位异常事件前后的记录；较长的采样空档留白。
- **任务记录**：手动记录编译、渲染等工作的时长、平均与峰值指标，并导出结果。
- **数据管理**：按范围导出监控、事件和任务 CSV；完整 JSON 备份带 SHA-256 校验，恢复前自动保存安全副本；支持按类别清理记录。
- **文件清理**：后台扫描限定范围的旧缓存、轮转日志与 Xcode 构建产物；默认不勾选，预览路径、确认后移入废纸篓，支持清理历史与按批次恢复。
- **存储分析**：查看开发环境或手动所选目录的占用，按名称、路径、占用和处理建议筛选排序；提供大型项目、排除目录、本地扫描记录与 CSV 报告，只分析，不删除文件。
- **内存回收**：真实内存读数、本应用分配器回收，以及需管理员授权的系统文件缓存回收；展示实际结果，不承诺提速或清空 Swap。
- **日常设置**：主动网络诊断、登录启动、系统通知、深浅主题。独立设置窗口包含“模块设置、外观、数据、关于”。

主窗口左侧包含概览、应用、回看、任务、网络、清理和存储七个页面。点击右上角齿轮或按 ⌘, 打开设置；⇧⌘E 直达数据页。默认 ⌥⌘G 呼出面板，可在设置中切换为 ⌥⌘M。⌘W 关闭窗口后仍继续监控，⌘Q 完全退出。

## 清理范围与恢复

“清理”页只扫描限定目录，扫描不会移动文件，也不会提权扩大范围：

- 用户 Library/Caches 下归属明确、至少 7 天未修改的应用缓存，以及同样达到 7 天保留期的指定 npm、pip、Poetry、Homebrew、Gradle 缓存目录。开发工具仅检查明确列出的缓存子目录，不把工具环境整体列为清理对象。
- 用户 Library/Logs 下归属明确、达到 30 天保留期的轮转日志。日志属于历史记录，不能重新生成。
- Xcode DerivedData 下达到 7 天保留期的 Build/Intermediates.noindex、Build/Products 和指定编译缓存；不删除完整项目目录、源代码或 SourcePackages。

系统管理的 com.apple.* 缓存与日志不列入清理候选；Xcode 仅按上述独立规则检查指定构建目录。进入候选目录前先检查根条目的修改时间，未到保留期即跳过。普通文件只检查元数据，不打开文件内容；目录遍历不跟随符号链接。

所属应用及相关工具进程必须已退出。归属不明、运行状态不明、权限不足或文件元数据无法核验时会跳过；不扫描文稿、下载目录、应用资料库、钥匙串或搞系列资料。缓存通常会重新生成，清理后首次使用或编译可能变慢。

停止扫描及扫描预算在检查点生效，属于软限制；若文件系统操作尚未返回，需要等待当前操作结束，不能保证立即停止或固定时限完成。

结果按类型分组，显示路径和估算占用，可在 Finder 中定位。候选默认不选，确认后才移入废纸篓；执行前再次检查状态和文件变化。**移入废纸篓不会立即释放磁盘空间**，本应用不自动清空废纸篓。

“清理历史”显示每批日期、已处理占用、状态摘要和待恢复数，可“恢复此批”；早期无时间的记录明确标注时间未知。“恢复上次清理”尝试恢复最近一次仍有未恢复项目的记录。待恢复数来自本机记录，不保证对应文件仍在废纸篓。原位置已有新文件、内容改变、应用仍运行或找不到原项目时会跳过，不覆盖现有文件。恢复需要本机清理记录及废纸篓或安全暂存中的文件；手动清空废纸篓后可能无法恢复。监控数据的 JSON 备份不打包被清理的文件。

## 本机存储分析

“存储”页显示个人目录所在磁盘的当前可用容量，并由用户主动选择“分析开发环境”或“选择目录”。首次打开不会自动扫描整个个人目录，扫描只读取本地元数据，不读取文件内容或上传数据。

开发环境分析覆盖已知路径中的 Xcode、Node.js、Python、Gradle/Maven、Android、Homebrew、Docker、本地模型和编辑器占用。已安装环境、虚拟磁盘、模型和运行数据仅展示占用及处理建议，不当作垃圾，也不自动删除。自选目录分析展示主要子目录与大型本地文件，可在 Finder 中定位。

结果支持搜索名称、路径与分类，按占用、名称或文件数排序，并按原始处理建议筛选。数值是已确认的分配空间估算；APFS 共享、克隆或稀疏文件可能使其与磁盘总占用不同，大型文件可能与目录汇总重叠，不能累加为可清理空间。

排除目录及其子目录在下一次分析时跳过；这些排除规则只影响分析，不修改清理页的独立保护范围。权限不足、云端占位、符号链接、其他挂载卷、扫描期间变化或达到扫描预算时，会保留说明并标注未完成，不把部分结果称为整个范围的总量；不会为占位文件主动下载内容。

本机保留最近 30 次扫描记录，趋势只比较同一范围的完整记录，未完成记录单独标注。CSV 报告导出本次扫描全部结果与说明，不受界面的搜索筛选影响；报告含实际路径与名称，仅保存到所选本地位置，请按自己的分享范围保管。

默认分析不访问 Apple 系统及搞系列缓存，也不自动进入 Docker 的沙盒虚拟机目录。Docker 虚拟机、镜像与卷应通过 Docker 自身管理；未统计范围会在扫描说明中列出。

## 内存回收的含义

清理页读取内存压力、已用、空闲、文件缓存、可清除内存、压缩内存和 Swap。页面可见时每 5 秒刷新；读数不可用时显示未知或未读取，回收前读取失败则不执行。

- **回收本应用**：调用系统分配器的 malloc_zone_pressure_relief，归还搞机灵自身可释放的闲置分配。返回字节数可能为零，不涉及其他应用的堆内存。
- **回收系统文件缓存**：通过系统管理员授权调用固定的 /usr/sbin/purge；可取消授权，缺少工具、失败或超时会报告结果。此操作面向系统文件缓存，不会清空应用占用或 Swap。

文件缓存有助于加快重复访问，压力正常时不必频繁回收。程序不关闭其他应用，不通过大量分配内存制造压力，也不保证改善性能。系统前后读数会受到其他活动影响，不能将差值称作本次实际释放量。

## 数据与统计口径

本机数据目录：

    ~/Library/Application Support/GaoSeries/GaoJiLing/

普通监控不上传数据，也不读取浏览器历史、屏幕或剪贴板。网络诊断仅在主动执行时进行 DNS、默认网关探测和用户指定域名的 HTTPS HEAD 请求。备份与导出可能包含应用名称、任务名称和监控记录，请按自己的分享范围保管。

数据库默认保留 7 天，可在设置中调整。历史通常每 10 秒保存一次，较早记录按分钟降采样，因此导出记录数可能少于实时图表中的采样点。回看导出遵循所选时间范围；定位事件后，范围为事件前所选时长至事件后 5 分钟。

CPU 与应用 CPU 统一采用全机 0–100% 口径，与活动监视器的单进程百分比口径不同。缺失传感器显示不可用；异常规则提供观测线索，不保证判断因果。暂停、休眠或未运行期间不补造数据。

公开仓库包含源码、测试、图标及文档；运行数据、导出、凭据和构建中间产物不进入版本库。安装包及其校验文件通过 GitHub Releases 提供。

## 从源码构建

需要 Apple Silicon Mac、完整 Xcode 及其命令行工具、macOS 14 或更新 SDK，以及 Python 3。

    ./Scripts/test.sh
    ./Scripts/build.sh

构建输出为 Release/GaoJiLing-1.09.dmg 及对应的 .sha256 文件。构建使用专属临时目录，并在退出时清理。

如需使用项目安装脚本：

    ./Scripts/install.sh

脚本需要对 /Applications 有写权限。它会校验应用标识、版本和签名，暂存新应用并退出旧进程。升级前将本应用资料目录全部文件、数据库、目录内附件和偏好设置备份到同级 GaoJiLing-Backups 私有目录并核验，随后替换应用、验证启动和数据保留。备份还包含由本应用恢复记录引用、通过身份核验的待恢复暂存或废纸篓实物，不备份整个废纸篓。

升级安全备份位于 ~/Library/Application Support/GaoSeries/GaoJiLing-Backups/，长期保留，不随旧版清理，也不进入源码或发行包。资料缺失、不可读或备份校验失败时停止替换；安装失败保留旧程序与备份。验证成功后才清理旧应用、旧本地安装包和中间构建，并只处理本应用的失效系统登记，不全局重置其他应用登记。手动拖入安装前，可先在设置“数据”页导出监控备份。

版本以 VERSION 文件为准。后续正式发布运行：

    python3 Scripts/bump-version.py

每次正式更新版本号准确增加 0.01、构建号增加 1；同一未交付版本的修复和重新构建不递增版本。正式发布均需核对更新前后的历史、任务与设置保留情况，安装替换并验证新版启动，再清理本项目旧应用、旧安装包及中间构建产物，不删除用户数据或安全备份。源码同步 GitHub，DMG 与 SHA-256 校验文件发布到对应版本的 GitHub Release；DMG 不提交到 Git 历史。
