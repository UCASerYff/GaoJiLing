# 搞机灵 V1.16 for Windows

面向 Windows 10/11 x64。桌面窗口显示 V1.16，关于页显示构建 2，命令行显示 1.16+2。使用按用户安装的 x64 MSI，无需管理员权限。安装包未进行 Authenticode 签名。

## 安装与运行

从发布页下载 `GaoJiLing-1.16+2-Windows-x64.msi` 和同名 `.sha256`，用 `Get-FileHash -Algorithm SHA256` 核对后运行 MSI。升级前先从通知区域退出旧版。若旧版使用自定义安装目录，请继续用 `INSTALLDIR` 指定原目录。从开始菜单打开搞机灵。主窗口优先使用本机 WebView2 Runtime，系统未提供该组件时使用 Microsoft Edge 应用窗口或系统浏览器。

关闭主窗口后继续采样。在 Windows 通知区域右键图标，可打开主窗口、设置或退出。在桌面唤起条上点击或短暂停留，或按 Ctrl+Alt+G（可改为 Ctrl+Alt+M）可打开浮层。拖动唤起条或浮层顶部的 CPU 区域可以移动位置。鼠标移出或点击外部可收起，也可按 Esc。Ctrl+, 打开设置，Ctrl+Shift+E 打开数据设置。全局快捷键冲突、通知投递和登录启动状态由 Windows 报告。

构建 1 的卸载流程会移除旧登录快捷方式。如果之前开启了登录启动，升级后可在模块设置里核对 Windows 登记状态并重新开启。

## 工作区

| 页面 | Windows 操作 |
| --- | --- |
| 概览 | 四项核心读数、共用时间轴的 CPU 与内存趋势、活跃应用排行和设备状态。可进入维护页核对指标来源。 |
| 应用 | 搜索应用或进程，按全机 CPU 或工作集排序，并可打开任务管理器。第一次缺少 CPU 基线的读数显示不可用。 |
| 回看 | 10 分钟、1 小时、24 小时范围，按异常事件定位并导出。将焦点移至图表，可用方向键查看实际采样点。采样空档留白。 |
| 任务 | 同一页开始和结束记录，查看实时计时、CPU 峰值及均值、内存峰值和逐项 CSV。上次运行中断时收尾到最后一次实际采样。 |
| 网络 | 手动检查本机连接、网关、输入域名的 DNS 和 HTTPS。 |
| 清理 | 扫描可验证归属的过期应用或开发工具缓存及轮转日志，逐项确认移入 Windows 回收站，按批恢复。内存区可请求收缩本进程工作集。 |
| 存储 | 开发环境和所选目录的元数据树、比例磁盘地图、钻取、排除、搜索排序、同范围完整历史和 CSV。重复文件与普通 NTFS 镜像在各自页签单独确认内容读取。 |
| 维护 | 按指标核对采样时间、来源、不可用或过期原因，设置电池读数阈值提醒。 |
| 应用管理 | 查看已安装应用，通过 Windows 设置走厂商卸载。对可验证的独立程序目录单独复核、移入回收站并按批尝试恢复。 |
| 交接 | 本地导入 `.gaoaction` 目录，复核来源声明和引用，确认后进入对应业务。只能用实际分析或移动回执生成结果。 |

Windows 通知由系统通知设置及专注模式决定是否显示。登录启动在正式安装并由本人启用后登记。监控和窗口通信只使用本机回环，联网诊断按需连接指定主机。

## 平台范围

- 进程 CPU 以整机总容量为 100%。Windows 物理内存压力来自系统内存负载估算，磁盘、GPU 与热区依赖本机性能计数器。固件或权限未提供的温度、功耗、硬件健康和风扇转速显示具体缺项。电池和散热是只读监测。
- Windows 的清理路径采用本系统的已知缓存和轮转日志规则。日志至少保留 30 天，缓存至少 7 天。路径、归属或运行状态无法核验时跳过。回收站中的项目仍占用磁盘空间，恢复会避开原位置的新内容。
- 卷枚举要求可证实的内置物理设备拓扑，通过 Windows 提供的盘符和公开元数据工作。系统拒绝设备映射或归属不明时显示原因。普通 NTFS 镜像支持已核验的父路径、搜索、报告和普通默认流提取。压缩、加密、稀疏、命名流和不支持的扩展记录无法提取。目录观察有上限。提取仅写入新文件。
- 统一确认第三方应用未保存状态、强制收缩系统文件缓存、充电限制和风扇写控制没有启用。Windows 系统安装应用使用 Windows 设置及厂商的权限和卸载流程。Windows 交接通过显式导入和导出开展。
- 文件扫描、内容分析和卷读取在系统调用之间检查取消与预算。已发出的调用可能需等待 Windows 返回。

## 资料与兼容性

默认资料目录仍为 `%APPDATA%\GaoSeries\GaoJiLing`。安装和卸载只处理程序，资料留给本机用户。数据库使用既有的 `monitor.sqlite` 表和时间格式，`panel.json` 保留已保存的横纵位置。清理、重复文件、卸载和交接的日志及待恢复项目属于业务资料。

如果正在运行旧的便携版，先退出旧版，再从开始菜单打开新版。两版共享默认资料目录，日常应由一个实例使用。

历史通常每约 10 秒保存一次。历史和事件默认保留 7 天，可设置 1–30 天。超过 24 小时的采样按分钟保留实际数据点。任务独立保留。设置内可按时间和类别导出 CSV，或导出带 SHA-256 完整性检查的监控 JSON。恢复完整 JSON 会替换所选资料，不自动备份被替换的内容。资料和导出可能含本机路径及名称，应留在本机。

## 构建与检查

使用干净的 x64 CPython 3.12 环境。在 `windows` 下执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Python <虚拟环境中的 python.exe>
```

脚本运行测试并在 `windows/dist` 生成安装包和 SHA-256 文件。隔离冒烟用 `smoke-installed.ps1 -Package <MSI 路径> -Python <python.exe>`。传入 `-PreviousPackage <构建 1 的 MSI 路径>` 可核对 Windows Installer 从旧构建升级。冒烟校验原包摘要，使用独立的 MSI 标识与合成资料执行安装、运行和卸载。

运行 `GaoJiLing-cli.exe --version` 查看版本。用 `--inspect` 查看资料条数，或用 `--serve --no-browser --data-dir <隔离目录> --port <本机端口>` 进行独立调试。

## 构建 2 验收

- 干净的 x64 CPython 下通过 50 项测试。覆盖监控历史和任务、权限失败、清理与恢复、重复文件、卷镜像和外部交接。
- 在 Windows 11 使用真实 Windows Installer 验证私有标识下从 1.16+1 升级至 1.16+2、启动两个 x64 程序和卸载。升级前后核对隔离数据库与浮窗位置。新构建读回旧任务、深色主题、14 天保留期和 Ctrl+Alt+M 设置，写入新任务后正常退出，卸载保留资料。
- 在 Edge 离屏核对十个工作页、独立设置入口、浅色、深色、窄窗与 150% 渲染，以及表单、图表键盘操作和确认取消。离屏流程和数据均由测试脚本生成。
- 离屏测试源为 `tests/visual_fixture.py` 和 `tests/visual_smoke.mjs`。前者只在新建的合成工作目录启动本机服务，后者连接独立的 Edge 调试端口，执行检查并写入所选截图目录。
- 在非活动 Windows 桌面核对原生唤起条、全局快捷键、浮窗非激活、暂停和收起，另检查浮窗浅深色、状态缺项、窄窗滚动和 150% 绘制。
- Windows 10 实机、实体外接卷、物理指针跨屏拖动、实际注销再登录和通知横幅未在本轮现场验收。
