搞机灵 V1.16 · Windows 10/11 x64 使用说明

从开始菜单打开搞机灵。关闭主窗口后，程序继续在通知区域采样。右键通知区域图标可以打开主窗口、设置或退出。
点击桌面唤起条、在条上停留，或按设置中的全局快捷键 Ctrl+Alt+G / Ctrl+Alt+M 呼出浮层。拖动唤起条或浮层顶部的 CPU 区域移动。移出浮层、在外部点击或按 Esc 收起。使用 Ctrl+, 打开设置，Ctrl+Shift+E 打开数据设置。

概览查看实时读数和近期趋势。应用页按全机 CPU 或进程工作集排名。回看页可选 10 分钟、1 小时、24 小时，按事件定位时，范围包含事件后的 5 分钟。任务页记录开始、结束及资源峰值。关闭主窗口仍继续记录，暂停采样时任务计时照常。

网络诊断只在点击后连接所选主机。维护页显示指标的真实来源以及读数不可用或过期的原因。电池阈值通知受 Windows 通知设置影响。

清理候选默认不勾选。先检查路径和保留期，再确认移入 Windows 回收站。通过批次记录尝试恢复，原位置有新内容时不会覆盖。存储占用分析只看元数据。重复内容分析和普通 NTFS 镜像须另行确认内容读取。镜像提取和报告写入新文件。已安装的注册表应用由 Windows 或厂商管理。独立应用目录通过归属、运行状态和内容复核后才可移动。

交接页从本机接收 .gaoaction 目录。查看来源声明和引用，确认后进入对应工作页。结果随真实分析或移动回执记录，并可主动导出。

监控资料保存在 %APPDATA%\GaoSeries\GaoJiLing。数据设置可导出 CSV 或完整 JSON。恢复完整 JSON 会替换监控记录，且不会自动创建替换前备份。清理、卸载和重复文件恢复记录是现用业务资料。

Windows 发行包没有 Authenticode 签名。公开文件系统与硬件接口未能返回数据时，界面显示不可用。Windows 版没有适用于所有应用的未保存状态确认，因此保持自动退出现有关闭状态。Windows 版不提供充电控制、风扇控制或系统文件缓存强制清空。
